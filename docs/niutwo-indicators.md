## 计算和展示边界

- 分析引擎及绘图函数从 NiuTwo 导入为独立 JavaScript，本工程运行不依赖兄弟工程路径或微信环境。导入文件头保留源文件 SHA-256；原工程保持不变。
- 保留 NiuTwo 的历史形态识别、评分和对象确认时点；将价格最小单位从股票的 0.01 元适配为 ETF 的 0.001 元（包括两处以最小单位作下限的容差）。当前状态的取样范围与生命周期校验由本工程修正，默认股票引擎同样应用修正。
- 行情页与策略页的日 K 统一使用最近 60 根判断摆动趋势、当前市场状态、Always-In 和区间内位置；完整已加载历史继续用于背景结构及历史图层。当前区间从全部候选中选择，不受历史图层最多显示 4 个高分区间的限制；仅采用起点在窗口内、截至当日已知且仍延续的区间。已失败、已突破结束、价格已离开的新确认区间及越过收敛顶点的三角形不再主导当前状态；等待突破跟进的区间最多延续原规则的 2 根 K 线。历史标记仍按其原有状态保留。
- Always-In 表示规则识别的方向倾向，本身不触发买卖。已确认突破及跟进可以独立建立方向，无需等新的摆动高低点全部确认；突破边界与确认时点必须在结构窗口内。每次分析重新检查突破后的所有收盘，越过原边界超过一跳即终止这次方向依据，不能因为后来再次越界而复活。最近一次已确认突破失败后，不回退到更早的成功突破；新的反向确认可以改变方向。
- 明确方向还需近期价格与 EMA20 一致：最近 5 根中至少 3 根同侧收盘、末日收盘在同侧、5 个 EMA 点首尾变化同向；价差与均线变化均需超过 `max(一跳, 0.05 × ATR14)`。单靠 EMA 不建立方向。无有效突破时，取窗口内最近两个已确认高点和两个已确认低点，高低点均抬高超过一跳可支持偏多，均降低超过一跳可支持偏空；不按主要／次要等级筛除近期点，也不要求累积三分。低点抬高和高点降低混合、未确认点或数量不足均不建立方向。上涨的最近低点、下跌的最近高点从自身确认日起必须持续被收盘守住，后来的另一个高点／低点不能复活已经失守的边界。
- 旧突破失效后允许新的已确认摆动结构恢复方向：上涨保护低点／下跌保护高点必须形成于旧突破失效之后，且整个高低点组合截至当天已确认、均线同向。失效前形成、失效后才确认的旧点不算新依据。方向解释展示实际高低点价格、确认日期和保护边界；未确认突破、失效依据、均线方向冲突或平坦整理保持“不明”。
- 市场状态使用上述当前方向评估趋势强度；局部区间存在而方向依据仍有效时显示“上升／下降趋势内整理”，不会只因 K 线重叠就清除方向。原 `trend` 字段仍记录已确认摆动的几何结构，可能落后于当前突破方向。历史回顾始终先截断后续行情再计算；详见 [粮食 ETF 方向核验](grain-direction-audit.md)。
- EMA20 与 NiuTwo 一致：前 20 根有效收盘价均值作为初值，以 2/21 权重递推。这里使用接口提供的全部日线，改变显示范围不改变同日 EMA 值；缺失收盘价后重新预热。历史长度不同仍会与另一终端存在差异。
- 价格行为分析使用截至图中显示末日的所有完整日线；翻页会截断后续数据再计算，不使用显示末日之后的行情。鼠标或键盘光标用于查看日线和当日标记，不将整个结构重算到光标日。标记锚点日期不等于可知日期；单日读数在存在相关字段时显示可知日和状态截止日。
- 摆动高低点需左右各 3 根，右侧第 3 根收盘后方可确认。未识别形态时没有标记；历史不足 20 根或存在异常 OHLC 时明确报告不可用，不补造结构。
- 高周期背景从现有前复权日线合成周 K。首周可能从周中开始、尾周可能仍在形成，因此保守剔除这两组；至少 20 根合成周 K 才进行周线分析，标出来源日期和周数。此实现没有额外下载周线，与 NiuTwo 直接加载周线的历史覆盖长度可能不同。
- 主图 SVG 保留蜡烛、MA/BOLL/DC、EMA20 和交互，透明 Canvas 图层沿用 NiuTwo 标记与防碰撞布局，并使用同一价格范围、日期间距和历史偏移。成交量和 MACD 继续独立纵轴。绘图只显示当前范围内的标记及价位；图层读数统计截至显示末日的全段已加载历史。
- 行情图与策略图统一默认开启 EMA20、MA60、成交量、支撑区域、压力区域、摆动点及结构失效线，结构摘要保留 ATR14 读数；其他图层默认关闭。偏好升级至 v2，旧版默认组合自动切换为精简组合，自定义选择按旧版完整默认值补齐后保留；行情和策略偏好仍独立保存。「恢复精简显示」重置全部指标勾选并保存。「常用结构」开启 EMA20、支撑、压力、趋势线、趋势通道；「全选结构／清空结构」只作用于 22 个价格行为选项。策略目标价沿用既有信号和数据对齐校验，不默认开启全量测量目标。
- 图表勾选仅控制展示。自动交易另由「裸 K 价格行为」策略适配器复用本引擎的部分形态与结构，不以勾选数量投票；周期、入场、退出、做 T 与确认规则见 [裸 K 自动模拟交易](price-action-strategy.md)。

## 维护与验证

按明确指定的源工程重新导入：

```bash
node scripts/import_niutwo.mjs /Users/dijunkun/SourceCode/NiuTwo
pnpm --dir web exec prettier --write src/price-action/engine.js src/price-action/renderer.js tests/fixtures/niutwo-price-action.json
pnpm --dir web test
```

导入脚本需要支持 `node:module.stripTypeScriptTypes` 的 Node.js（本机已用 Node 26 验证）；通过 `scripts/niutwo-current-state.mjs` 与 `scripts/niutwo-direction-control.mjs` 重放当前状态及方向修正，源代码锚点变化时停止导入，防止覆盖修正。日常构建和运行使用生成的普通 JavaScript，不需要 TypeScript 运行时。

保留 NiuTwo 固定 OHLCV 的历史分析对象快照和 Canvas 命令快照测试；该样例当前状态由旧失败区间修正为仍有效的紧密区间。另用粮食 ETF 截至 2026-09-09 的存储前复权数据回归：4 月失败三角形只作为历史背景，当日为宽幅牛通道、方向偏多；回顾至 4 月确认日不能提前得知其后失败。样例不是当年逐日存档，不用于证明实际成交。还验证全图层覆盖、ETF 最小单位、EMA 初值与缺失预热、周线首尾裁剪、缺失数据、历史截断、图层独立绘制及有限坐标。普通验证入口为 `bash scripts/validate.sh`。
